# investment-tools

Development tooling for reproducible investment-data artifacts.  The R01
StockFacts Generator Phase 1 implementation is documented in
[`docs/R01_GENERATOR_DESIGN.md`](docs/R01_GENERATOR_DESIGN.md).

> **Not production approved.** The current generator only reads an R01 package,
> builds a dry-run acquisition plan, and writes development execution evidence.
